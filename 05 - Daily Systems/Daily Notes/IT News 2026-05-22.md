## 🔐 Cybersecurity

### 🚨 ShinyHunters อ้าง 275M records จาก Canvas/Instructure
**ShinyHunters** ออกแถลงรับผิดชอบโจมตี **Instructure (Canvas)** — claim ขโมยข้อมูล **275 ล้าน records** ของนักเรียน/อาจารย์/staff:
- **8,809 school districts/universities** affected (รวม NUS Singapore จากข่าวเมื่อ 10 พ.ค.)
- เป็นการเปิดเผยขนาดจริงของ Canvas breach (ก่อนหน้ารายงานแค่ ~9K สถาบัน)

### Critical CVEs ใหม่
| CVE | Detail | สถานะ |
|---|---|---|
| **CVE-2026-9082** | Information disclosure → PrivEsc → RCE, **no auth** | สูง |
| **CVE-2026-46333** | Improper privilege management → root | 5.5 (Local) |
| CVE-2025-61882 (Clop using) | Oracle E-Business Suite | 9.8 — Allianz UK ถูกโจมตี |
| MiniPlasma (cont.) | Windows SYSTEM 0-day | PoC released, unpatched |

> [!danger] ShinyHunters — Canvas LMS 275M records confirmed
> Scope ขยายจาก 9K สถาบัน → 275 ล้าน records จริง — เด็กนักเรียน/อาจารย์ ทั่วโลกต้องเปลี่ยน password ทันที + เปิด MFA

> [!warning] Allianz UK × Clop × CVE-2025-61882
> Clop ransomware ใช้ช่องโหว่ Oracle E-Business Suite (CVSS 9.8) — องค์กรที่ใช้ Oracle EBS ต้อง patch ด่วน
