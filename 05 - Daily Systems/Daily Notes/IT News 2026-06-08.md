### 🔍 Deep Dive: Anthropic ทะยานแซง OpenAI

Anthropic ประกาศปิด financing round ที่ valuation **$965 พันล้านดอลลาร์** แซงหน้า OpenAI — พร้อมยื่น IPO แบบ confidential ต่อ SEC ซึ่งนับเป็นสัญญาณสำคัญว่าบริษัทพร้อมเข้าตลาดหุ้น ฐานความแข็งแกร่งหลักมาจาก **Claude Code** ซึ่งครองตลาด AI coding assistant และสร้าง recurring revenue จากฝั่ง enterprise อย่างแข็งแกร่ง

Opus 4.8 เพิ่ม default context window เป็น **1 ล้าน token** — หมายความว่า developers สามารถโหลด codebase ทั้งโปรเจกต์ขนาดใหญ่เข้าไปใน context เดียว ซึ่งเปลี่ยนกระบวนการ code review, refactoring และ architecture planning อย่างมีนัยสำคัญ

## 💾 Hardware & Semiconductor

### Nvidia RTX Spark Superchip

Nvidia CEO Jensen Huang เปิดตัว **RTX Spark Superchip** ที่งาน Computex ไต้หวัน โดยเป็นการรวม Blackwell RTX graphics + Grace CPU เข้าด้วยกันบน process node **3nm ของ TSMC** สำหรับ Windows PCs ที่จะวางจำหน่ายปลายปี 2026 จาก OEMs หลัก ได้แก่ Microsoft, Dell, HP, ASUS, Lenovo และ MSI

| ประเด็น | รายละเอียด |
|---|---|
| สถาปัตยกรรม | ARM-based (Grace CPU + Blackwell GPU) |
| Process Node | TSMC 3nm |
| OEM Partners | Microsoft, Dell, HP, ASUS, Lenovo, MSI |
| เป้าหมาย | AI PC market — สู้กับ Apple Silicon |

## 🔐 Cybersecurity

### CVE ที่น่าจับตาวันนี้

| CVE | CVSS | ระบบที่ได้รับผลกระทบ | ประเภท | สถานะ |
|---|---|---|---|---|
| CVE-2026-20245 | 7.8 | Cisco Catalyst SD-WAN Manager | Command Injection (File Upload) | 🔴 Actively Exploited |
| CVE-2026-20182 | Critical | Cisco Catalyst SD-WAN Controller & Manager | Authentication Bypass | 🔴 Actively Exploited (UAT-8616) |
| CVE-2026-3300 | 9.8 | Everest Forms Pro (WordPress) ≤ 1.9.12 | Remote Code Execution | 🔴 Actively Exploited |
| CVE-2025-48595 | High | Android Framework | Integer Overflow / Local Privilege Escalation | 🔴 Actively Exploited |

> [!danger] Cisco SD-WAN — Zero-Day ที่ 6 ในปี 2026
> Cisco แพตช์ช่องโหว่ SD-WAN zero-day ที่ 6 แล้วในปีนี้ (CVE-2026-20182) ถูกใช้โดย threat actor **UAT-8616** โจมตีในลักษณะ targeted attack — ช่องโหว่นี้ทำให้ผู้โจมตีได้รับ admin privileges ผ่าน specially crafted packets โดยไม่ต้องมี credentials ใดๆ — **อัปเดตด่วน**

> [!warning] WordPress: Everest Forms Pro RCE (CVSS 9.8)
> ช่องโหว่ CVE-2026-3300 กระทบ Everest Forms Pro WordPress plugin ทุกเวอร์ชันถึง 1.9.12 (~4,000 installations) อนุญาตให้ผู้โจมตีรัน code บน server ได้โดยตรง — **อัปเดตหรือปิดใช้งาน plugin ทันที**

> [!warning] Android June 2026 Security Update — 124 CVEs
> Google ปล่อยแพตช์ประจำเดือน มิ.ย. แก้ไข 124 ช่องโหว่ รวม CVE-2025-48595 (zero-day ที่ถูก exploit อยู่จริงใน wild) — ดาวน์โหลดอัปเดตทันที
