### 🔬 Deep Dive: Anthropic Project Glasswing

Anthropic ปิด financing round ด้วย valuation **$965 พันล้านดอลลาร์** แซงหน้า OpenAI อย่างเป็นทางการ และยื่นเอกสาร IPO แบบ confidential แล้ว ควบคู่กันนั้น บริษัทเปิดตัว **Project Glasswing** — โครงการที่คัดเลือกองค์กรชั้นนำ (AWS, Apple, Cisco, Google, JPMorgan Chase, Microsoft) ให้ทดสอบ **Claude Mythos Preview** ซึ่งเป็น frontier model ที่ยังไม่เปิดสู่สาธารณะ โดยมีภารกิจหลักคือค้นหาและแก้ไข critical software vulnerabilities ในระบบของตัวเอง

นี่ถือเป็นสัญญาณว่า Anthropic กำลังวาง Claude ไว้ในโครงสร้างพื้นฐานของบริษัทใหญ่ระดับโลกก่อนการ IPO เพื่อสร้าง enterprise moat ที่ยากต่อการทดแทน

### 🔬 Deep Dive: เศรษฐศาสตร์ AI เปลี่ยนทิศ

โมเดลจีนอย่าง DeepSeek ราคาถูกกว่าคู่แข่ง **3–10 เท่า** ทำให้ปี 2026 กลายเป็นปีที่ "เศรษฐศาสตร์เอาชนะคุณภาพ" ในสายตานักลงทุน OpenAI มีรายได้ annualized เกิน **$25 พันล้านดอลลาร์** และกำลังเตรียม IPO ในปลายปี ขณะที่ WWDC 2026 ของ Apple นำเสนอ Siri AI ใหม่ที่มี back-and-forth dialogue, on-screen context awareness และ image editing แบบ on-device

## 💾 Hardware & Semiconductor

### Nvidia — RTX Spark Superchip

Nvidia เปิดตัว **RTX Spark Superchip** ที่งาน Computex รวม Blackwell RTX graphics + Grace CPU ในชิปเดียว คาดว่าจะปรากฏใน Windows devices จาก OEM รายใหญ่ภายในปลายปี นับเป็นการขยาย stack ของ Nvidia จาก data center ลงมาถึง consumer PC

### Intel — AI Chip Order จาก Alphabet

Intel ดีดตัว **+11.2%** เมื่อวันที่ 9 มิถุนายน หลังมีรายงานว่า Alphabet สั่งซื้อ AI chip ล็อตใหญ่ สัญญาณนี้ชี้ว่า hyperscalers กำลัง **diversify** supply chain ออกจาก Nvidia ซึ่งเป็น sentiment เชิงบวกต่อ Intel ในระยะกลาง

### ตลาด Semiconductor — ความผันผวนรอบสัปดาห์

| วันที่ | เหตุการณ์ | ผลกระทบ |
|---|---|---|
| 5 มิ.ย. | Broadcom outlook เชิงลบ + memory crisis | AMD -10.86%, Intel -11.28% |
| 9 มิ.ย. | Intel ได้ order AI chip จาก Alphabet | Chip stocks ฟื้นตัว |
| เม.ย. 2026 | ยอดขายโลก $110.5B | +11% MoM, +93.9% YoY |

> [!info] **Outlook 2026**
> Semiconductors อยู่ในวัฏจักรขาขึ้น driven by AI แต่มี structural bottleneck ด้าน advanced packaging, HBM memory, และ substrate supply ที่ยังคงกดดัน margin ผู้ผลิต

### Data Center Crisis

การวิเคราะห์พบว่า **30–50%** ของ data centers ที่วางแผนสร้างในสหรัฐฯ (~140 โครงการ รวม 16 GW) อาจล่าช้าหรือยกเลิก เหตุจาก transformer ที่ต้องรอหลายปี, การต่อต้านจากชุมชนเรื่องพลังงานและน้ำ, และปัญหาการเชื่อมต่อกริด

## 🔐 Cybersecurity

### Microsoft June 2026 Patch Tuesday — 200 CVEs / 6 Zero-days

Microsoft ปล่อย Patch Tuesday ประจำเดือนมิถุนายน แก้ไขช่องโหว่รวม **200 รายการ** โดยมี **6 zero-day** (1 ที่ถูกใช้โจมตีแล้ว, 5 ที่เปิดเผยต่อสาธารณะแล้ว)

| CVE | ชื่อ | CVSS | ประเภท | ความรุนแรง |
|---|---|---|---|---|
| CVE-2026-50507 | YellowKey | — | BitLocker Bypass (ต้องเข้าถึงทางกายภาพ) | High |
| CVE-2026-49160 | HTTP/2 Bomb | — | DoS — unauthenticated, remote | Critical |
| CVE-2026-45657 | Windows Kernel UAF | 9.8 | Use-After-Free, RCE | Critical |

> [!danger] **CVE-2026-45657 — CVSS 9.8**
> Windows Kernel use-after-free vulnerability ที่อาจนำไปสู่ RCE ควร **patch ทันที** สำหรับ Windows endpoints ทุกตัวในองค์กร

> [!warning] **CVE-2026-49160 — HTTP/2 Bomb**
> Unauthenticated attacker สามารถทำให้ server หมด memory ผ่าน crafted HTTP/2 frames — เสี่ยงสูงสำหรับ internet-facing web servers ที่รัน IIS

### Microsoft GitHub Supply Chain Incident

Microsoft ยืนยันว่าถูกบุกรุก โดยผู้โจมตีสามารถ inject **information stealer** เข้าไปใน **73 open-source projects** บน GitHub ทำให้ Microsoft ต้องถอด repository บางส่วนชั่วคราว เหตุการณ์นี้เน้นย้ำความเสี่ยง **software supply chain** ที่ยังคงเป็นภัยคุกคามอันดับต้นๆ ในปี 2026
