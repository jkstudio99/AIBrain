## 🔐 Cybersecurity

### 🚨 CVE-2026-20182 — Cisco SD-WAN (CVSS 10.0)

| Field | Detail |
|---|---|
| Product | Cisco Catalyst SD-WAN Controller + Manager (on-prem + cloud) |
| CVSS | **10.0 (Critical)** |
| Type | Authentication bypass → admin privileges |
| Actor | **UAT-8616** (Talos tracking) |
| KEV deadline | **17 พ.ค.** (3 วันเท่านั้น — rare) |
| Status | Patch ออกแล้ว, exploit อยู่ในวิถี |

> [!danger] CVE-2026-20182 — Cisco SD-WAN ใช้แล้ว 0-day
> CISA ให้ federal **เพียง 3 วัน** patch (deadline 17 พ.ค.) — short deadline แบบนี้สงวนสำหรับ urgent threats เท่านั้น
> KEV list มี Cisco SD-WAN รวม **15 CVE** ปีนี้ 5 ใหม่: CVE-2026-20128, 20122, 20133, 20127, 20182

### Five Eyes Joint Advisory
- รัฐบาล 5 ประเทศ (US/UK/CA/AU/NZ) ออก joint warning เรื่อง Cisco zero-day campaign
- บางเหตุการณ์ย้อนได้ถึง **2023** — long-running operation
- คาดเป็น state-sponsored
