### 🔍 Deep Dive: Anthropic กำลังเข้าใกล้ไตรมาสที่ทำกำไรครั้งแรก

Anthropic รายงานว่ากำลังจะมีไตรมาสที่ทำกำไรครั้งแรกในประวัติศาสตร์ของบริษัท โดย Q2 2026 มีรายได้คาดการณ์ที่ **$10.9 พันล้าน** และกำไรจากการดำเนินงานประมาณ **$559 ล้าน** ซึ่งถือเป็น milestone สำคัญสำหรับบริษัท AI ที่ก่อตั้งมาเพียง 3 ปี ควบคู่กับการเจรจา funding round มูลค่า **$900 พันล้าน** ซึ่งจะทำให้ Anthropic กลายเป็นหนึ่งในบริษัท private ที่มีมูลค่าสูงที่สุดในโลก

นอกจากนี้ AWS และ Anthropic ได้ลงนามในข้อตกลงมูลค่า **$100 พันล้าน** เพื่อจัดหา Trainium capacity 5 กิกะวัตต์จนถึงปี 2036 ซึ่งเป็นสัญญาณชัดเจนว่า hyperscaler ทั้งหลายกำลังผนึกกับ AI labs เพื่อสร้าง "enterprise nervous system" ที่ครบวงจร

### 🔍 Deep Dive: GPT-5.5 และสงคราม Benchmark AI

OpenAI เปิดตัว GPT-5.5 ซึ่งทำสถิติใหม่ในงาน agentic coding และ computer use — benchmark Terminal-Bench 2.0 ที่ **82.7%** และ OSWorld-Verified **78.7%** บ่งชี้ว่าโมเดลสามารถทำงานอัตโนมัติในระบบจริงได้อย่างมีประสิทธิภาพสูง ขณะที่ DeepSeek ออก V4-Pro/Flash ที่ใช้ Mixture-of-Experts architecture พร้อม context window 1 ล้าน token ทำให้ต้นทุน inference ลดลงอย่างมีนัยสำคัญ เป็นการกดดัน OpenAI ในด้านราคาต่อประสิทธิภาพอีกครั้ง

> [!warning] CVE-2026-41089 — Windows Netlogon RCE
> CVSS 9.8 — ผู้โจมตีสามารถส่ง crafted network request ไปยัง Domain Controller เพื่อ stack-based buffer overflow และรัน code โดยไม่ต้องยืนยันตัวตน — **ระบบ AD/DC ทุกแห่งต้องแพ็ชด่วน**

> [!warning] CVE-2026-42897 — Exchange Server Spoofing (CISA KEV)
> ถูกเพิ่มใน CISA Known Exploited Vulnerabilities catalog แล้ว — มีการใช้งาน exploit ในโลกจริง

### 🚨 ข่าวการโจมตีล่าสุด

- **KimWolf DDoS Botnet**: ทางการสหรัฐและแคนาดาจับกุมชายชาวแคนาดาที่ดูแล botnet ที่ติดเชื้อเกือบ **2 ล้านอุปกรณ์** ทั่วโลก
- **Laravel Lang Supply Chain Attack**: ตรวจพบ package เวอร์ชัน 700+ เวอร์ชันที่เป็นอันตราย บน npm ระหว่าง 22-23 พ.ค. 2026 — เป็นสัญญาณ automated mass tagging attack
- **CVE-2026-9082 (Drupal RCE)**: SQL injection ใน Drupal Core ทุก version ที่ supported — กำลังถูกโจมตีกับเว็บไซต์หลายพันแห่ง
- **cPanel Zero-Day**: ถูกใช้โจมตีเว็บไซต์รัฐบาล Guam
- **HDFC AMC**: ถูก cyberattack วันที่ 16 พ.ค. มีการเปิดใช้ incident response

> [!danger] Mandiant M-Trends 2026
> **28.3% ของ CVE ถูก exploit ภายใน 24 ชั่วโมง** หลังเปิดเผย! บางกลุ่มอาชญากรสามารถ lateral move ข้ามเครือข่ายได้ภายใน **30 วินาที** ด้วยความช่วยเหลือของ AI — ทีม security ต้องเร่ง automation และ patch cycle

## ☁️ Cloud & Enterprise IT

### 🏆 AI Cloud War: AWS vs Google vs Azure

ทั้งสาม hyperscaler กำลังแข่งขันสร้าง "full enterprise AI stack" ครบวงจร — จากชิป custom ไปจนถึง agent framework และ vertical solutions:

- **Microsoft**: เปิดตัว "Intelligent Purview" ป้องกัน data leakage ใน AI prompts/responses แบบ real-time; "Azure Confidential AI" ใช้ AMD SEV-SNP สร้าง hardware enclave ที่แม้แต่ Microsoft เองก็ไม่สามารถดู data ได้
- **Google Cloud**: เปิดตัว Cross-cloud Lakehouse ที่รองรับ AWS, Azure, และ partner ecosystem ให้ agents เข้าถึงข้อมูลข้ามคลาวด์ได้ไร้รอยต่อ
- **AWS**: Trainium3 ใช้งาน 40% ของ AI training ภายใน Amazon แล้ว; ดีล $100B กับ Anthropic

### 🌐 US-China Tech Tensions

- จีนปฏิเสธว่าไม่เคยบังคับบริษัทเทคปฏิเสธนักลงทุนต่างชาติ หลังถูกถามถึงการกดดันบริษัทปฏิเสธเงิน US
- US-China ยังคงตึงเครียดใน AI chips, models, capital flows, และ tech supply chains
