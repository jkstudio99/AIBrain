### 🔬 Deep Dive: Anthropic Series H — $65 พันล้านดอลลาร์

Anthropic ประกาศระดมทุน Series H มูลค่า **$65 พันล้านดอลลาร์** เมื่อวันที่ 28 พฤษภาคม 2026 นับเป็นหนึ่งในการระดมทุนส่วนตัวที่ใหญ่ที่สุดในประวัติศาสตร์เทคโนโลยี ก่อนหน้านี้ในปี 2026 บริษัทได้รับการระดมทุน Series G มูลค่า $30 พันล้านดอลลาร์ที่นำโดย Coatue และ GIC ส่งผลให้มูลค่าบริษัทอยู่ที่ **$380 พันล้านดอลลาร์** ราคา Claude เมื่อเทียบการใช้งานที่ **$4,811** ต่อปียังคงสูงกว่า ChatGPT ($3,357) อย่างมีนัยสำคัญ ขณะที่ DeepSeek นำเสนอทางเลือกที่ **$1,071** ซึ่งถูกกว่าถึง 4.5 เท่า ทำให้เกิดคำถามว่า premium pricing จะยั่งยืนได้อีกนานแค่ไหน

## 🔐 Cybersecurity

### ⚠️ CVE Table — สำคัญประจำสัปดาห์

| CVE | CVSS | ระบบที่กระทบ | สถานะ |
|---|---|---|---|
| CVE-2026-42897 | 8.1 | Microsoft Exchange Server (On-Prem) | 🔴 ถูก exploit แล้ว, CISA KEV (deadline 29 พ.ค.) |
| CVE-2026-35616 | 9.1 | FortiClient Endpoint Management Server | 🔴 ถูก exploit แล้ว, pre-auth bypass |
| CVE-2026-39987 | Critical | Marimo notebook (≤0.20.4) | 🟠 ถูก exploit แล้วด้วย LLM agent |

> [!danger] CVE-2026-35616 — FortiClient EMS (CVSS 9.1) CRITICAL
> ช่องโหว่ pre-authentication API access bypass นำไปสู่ privilege escalation ใน FortiClient Endpoint Management Server ทุก deployment ที่ internet-reachable ควรอัปเดตทันที เนื่องจากถูก exploit อยู่ในป่า (in-the-wild)

> [!danger] CVE-2026-42897 — Microsoft Exchange Server XSS Spoofing (CVSS 8.1)
> CISA เพิ่มเข้า Known Exploited Vulnerabilities catalog เมื่อ 15 พ.ค. 2026 กำหนดให้หน่วยงานรัฐบาลกลางสหรัฐฯ แก้ไขภายใน 29 พ.ค. 2026 (ผ่านแล้ว) องค์กรที่ยังไม่ได้ patch ควรดำเนินการด่วน

> [!warning] CVE-2026-39987 — Marimo RCE + LLM-Powered Attack
> น่าจับตา: threat actor ใช้ LLM agent ทำ post-compromise actions หลัง exploit Marimo notebook — ดึง cloud credentials และ SSH private key จาก AWS Secrets Manager นี่คือตัวอย่างแรกๆ ที่มีรายงานอย่างชัดเจนว่า AI ถูกใช้ใน kill chain จริง
