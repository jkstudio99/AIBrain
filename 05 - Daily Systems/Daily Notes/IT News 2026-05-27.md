## 💾 Hardware & Semiconductor

### 🚨 Nvidia Rubin Spec Cuts
- **Rubin Ultra**: จาก **4-die/GPU → 2-die/GPU**
- Each chip scaled **4-chiplet → 2-chiplet**
- เปิดทางให้ **AMD MI500** ที่จะออก 2H 2027 มี window สู้
- Rumor: Rubin platform design issues = delay potential

### Samsung HBM4 ที่ ISSCC 2026
- **36 GB, 12-high HBM4 stack**
- **2048 IO pins** / **3.3 TB/s bandwidth**
- 6th-gen 10nm-class (1c) DRAM + SF4 logic base die
- ความเร็ว **13 Gb/s/pin**
- 16-Hi HBM4 contracts ที่ Nvidia กำลังเลือก: SK hynix/Samsung/Micron แย่งกัน

### GPU-HBM Separation Trend (TrendForce)
- อุตสาหกรรมเริ่มคุย separate package GPU + HBM
- เชื่อมผ่าน **optical links**
- ขยาย memory capacity ได้หลายเท่าจาก 2.5D ปัจจุบัน
