### 🔍 Deep Dive: Anthropic — Claude เขียนโค้ดแทนมนุษย์มากกว่า 80%

Anthropic ประกาศตัวเลขที่น่าตกใจว่า **ปัจจุบันโค้ดมากกว่า 80% ที่ถูก merge เข้า codebase ของ Anthropic เองเขียนโดย Claude** — ไม่ใช่โดยมนุษย์ นี่คือสัญญาณแรกที่ชัดเจนของ recursive self-improvement ที่บริษัทเคยพูดถึงในเชิงทฤษฎี ซึ่งหมายความว่าโมเดล AI กำลังช่วยพัฒนาโมเดลรุ่นต่อไปของตัวเอง

ควบคู่กัน Anthropic เปิดตัว **Claude Partner Network** รองรับ Services Track (บริษัทที่ให้บริการโซลูชัน Claude) และ Partner Hub ซึ่งเป็นตลาดกลางเชื่อมลูกค้ากับพาร์ทเนอร์ ถือเป็นการขยาย ecosystem ในเชิงธุรกิจอย่างจริงจัง

### 🔍 Deep Dive: Microsoft Build 2026 — MAI-Code-1-Flash & On-Device AI

Microsoft เปิดตัว **MAI-Code-1-Flash** โมเดล code-generation รุ่นแรกที่พัฒนาภายในองค์กร เพื่อลดการพึ่งพา OpenAI และลดต้นทุนให้นักพัฒนา พร้อมประกาศ **on-device AI agents** ที่ทำงานบนเครื่อง Windows โดยตรง ไม่ต้องส่งข้อมูลขึ้น cloud — สอดคล้องกับแนวทาง "reinvent the PC" ที่ประกาศร่วมกับ Nvidia ที่ Computex

## 🔐 Cybersecurity

### CVE โดดเด่นประจำสัปดาห์

| CVE | ระบบ | ความรุนแรง | สถานะ |
|---|---|---|---|
| CVE-2026-20182 | Cisco Catalyst SD-WAN Controller / Manager | Critical | Exploited (UAT-8616) |
| CVE-2026-42897 | Microsoft Exchange Server (On-Prem) | High | Exploited via crafted email |
| CVE-2025-8088 | WinRAR | High | Gamaredon กลุ่มรัสเซีย exploit |
| Android June 2026 batch | Android Framework + อื่นๆ | High (1) + others | Patched (124 CVE รวม) |

> [!danger] CVE-2026-20182 — Cisco SD-WAN Authentication Bypass
> **UAT-8616** (กลุ่มภัยคุกคาม Sophisticated) กำลัง exploit ช่องโหว่ authentication bypass บน Cisco Catalyst SD-WAN Controller และ Manager อยู่ในขณะนี้ ผู้ดูแลระบบควร **patch ทันที** และตรวจสอบ admin access logs ย้อนหลัง 30 วัน

> [!warning] CVE-2026-42897 — Microsoft Exchange RCE via Email
> ช่องโหว่นี้ถูก exploit ผ่าน **crafted email** โดยไม่ต้องให้ผู้ใช้คลิก เพียงแค่ Exchange Server ประมวลผลอีเมลก็ trigger ได้แล้ว (zero-click vector) — อัปเดต Exchange Server ด่วน

> [!warning] Weedhack MaaS Campaign (Minecraft-themed)
> Malware-as-a-Service ชื่อ **Weedhack** แพร่กระจายผ่าน Minecraft modpack ปลอม มี malicious JAR files มากกว่า 3,820 ไฟล์ ตรวจพบ URL จำหน่าย 240+ แห่ง — ระวังการดาวน์โหลด mod จากแหล่งที่ไม่น่าเชื่อถือ

### แนวโน้ม: AI-Assisted Attacks เร็วขึ้นสุดขีด

- กลุ่ม cybercriminal บางราย **เจาะเครือข่ายและ lateral move ใน < 30 วินาที**
- Zero-day vulnerabilities ถูก exploit เร็วขึ้นก่อนที่ patch จะพร้อม
- Anthropic เผยแพร่รายงาน mapping 1 ปี AI-enabled cyber threats
