| Field | Detail |
|---|---|
| Product | nginx — `ngx_http_rewrite_module` |
| Type | Heap buffer overflow |
| Vector | **Unauthenticated** crafted HTTP request |
| Impact | Remote Code Execution |
| Affected | **ทุก build ตั้งแต่ปี 2008** |
| Status | Patch ออกแล้ว, exploit chain เผยแพร่ |
