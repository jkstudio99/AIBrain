### 🔥 Deep Dive 1 — Musk v. OpenAI: Musk แพ้
**Elon Musk แพ้คดี** ต่อ OpenAI — closing arguments เสร็จแล้ว และ jury จะ deliberate สัปดาห์หน้าเพื่อตัดสินรายละเอียดค่าเสียหาย ในศาล Sam Altman ให้การว่า Musk ในปี 2017 **ยืนกรานต้องคุม for-profit arm** ของ OpenAI — สื่อตั้งฉายาคดีนี้ว่า "lies and selective amnesia"

### 🔥 Deep Dive 2 — MS–OpenAI Partnership Rewrite
**The New Stack** รายงานว่าโครงสร้างพันธมิตร MS–OpenAI ถูกเขียนใหม่ — ผ่อนคลายเงื่อนไข exclusive ที่ MS เคยมี ทำให้:
- **Anthropic** + **Google** มีโอกาสเข้าสู่ Azure ecosystem มากขึ้น
- OpenAI ได้ความยืดหยุ่นในการเลือก cloud (AWS, Oracle, Google)
- MS ลดความเสี่ยง vendor concentration

→ Implication: AI cloud landscape เปลี่ยน MS ไม่ได้ผูกขาด OpenAI อีกต่อไป

### 🔥 Deep Dive 3 — Microsoft Build 2026 เปิดวันนี้
