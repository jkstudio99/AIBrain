### 🔥 Deep Dive: Anthropic ทำลายสถิติรายได้ AI

Anthropic บันทึกการเติบโตรายได้ 80 เท่าเมื่อเทียบปีต่อปีใน Q1 2026 ทำให้ ARR (Annual Recurring Revenue) พุ่งสูงกว่า **$44 พันล้านดอลลาร์** นับเป็นการกระโดดรายได้ที่ชันที่สุดที่ frontier AI lab ใดเคยเปิดเผยต่อสาธารณะ ตัวเลขนี้ทำให้ Anthropic กำลังตามทัน OpenAI ในแง่รายได้ภายในระยะเวลาประมาณ 12 เดือน

ควบคู่กัน Anthropic ยังเปิดตัว **Project Glasswing** — โครงการด้าน cybersecurity ที่คัดเลือกองค์กรชั้นนำอย่าง AWS, Apple, Cisco, Google, JPMorgan Chase และ Microsoft เพื่อเข้าถึง Claude Mythos Preview ซึ่งเป็น frontier model ที่ยังไม่ปล่อยสู่ตลาด เป้าหมายคือค้นหาและแก้ไข critical software vulnerabilities ก่อนที่จะถูกนำไปใช้งานจริง

### 🔥 Deep Dive: รัฐบาลสหรัฐฯ เร่งกำกับดูแล AI Frontier Models

CISA's Center for AI Standards and Innovation ลงนามข้อตกลงกับ Google DeepMind, Microsoft และ xAI ของ Elon Musk อนุญาตให้รัฐบาลสหรัฐฯ **ประเมิน AI models ก่อนเปิดให้สาธารณชนใช้งาน** รวมถึงดำเนินการ pre-deployment evaluations และวิจัยด้าน AI security สำหรับ frontier capabilities ขณะเดียวกัน กระทรวงกลาโหมสหรัฐฯ ยังทำสัญญากับบริษัท Big Tech 8 แห่ง (ไม่รวม Anthropic) สำหรับระบบ AI ทางทหาร

## 🔐 Cybersecurity

### CVE Critical Table (สัปดาห์นี้)

| CVE | ระบบที่ได้รับผลกระทบ | ความรุนแรง | CVSS | สถานะ |
|---|---|---|---|---|
| CVE-2026-6973 | Ivanti EPMM | RCE (Remote Code Execution) | 7.2 | **Under Active Exploitation** — CISA deadline: May 10 |
| CVE-2026-31431 | Linux Kernel (Copy Fail) | Local Privilege Escalation → root | High | CISA KEV, กระทบ Kubernetes clusters หลายล้าน |
| CVE-2026-3854 | GitHub Git Infrastructure | RCE (authenticated) | Critical | ผู้ใช้ทุกคนสามารถ execute commands บน backend |
| CVE-2026-0300 | Palo Alto PAN-OS | Buffer Overflow → Unauthenticated RCE | Critical | Patch คาดออก 13 May 2026 |
| CVE-2026-23918 | Apache HTTP/2 | DoS / Potential RCE | Critical | กระทบ web servers ทั่วโลก |

> [!danger] CVE-2026-6973 (Ivanti EPMM) — Active Exploitation
> CISA กำหนด deadline แก้ไขภายใน **วันนี้ (10 May 2026)** สำหรับ federal agencies
> ช่องโหว่นี้อนุญาตให้ผู้ใช้ที่มีสิทธิ์ admin ระยะไกลสั่งรัน code บนเครื่อง server ได้
> **แนะนำ:** อัปเดต Ivanti EPMM เป็นเวอร์ชันล่าสุดทันที

> [!danger] CVE-2026-31431 (Linux "Copy Fail") — Kubernetes Mass Risk
> ช่องโหว่ privilege escalation ใน Linux kernel กระทบ cloud environments และ Kubernetes clusters **หลายล้านคลัสเตอร์**
> Microsoft Security Blog ยืนยันว่ากระทบ cloud Linux workloads ข้ามหลาย distributions
> **แนะนำ:** อัปเดต kernel packages และตรวจสอบ Kubernetes node images

> [!warning] CVE-2026-3854 (GitHub RCE) — Supply Chain Risk
> นักวิจัยพบว่า GitHub's internal Git infrastructure มีช่องโหว่ RCE ที่ authenticated user ทุกคนสามารถ exploit ได้ด้วย `git push` เพียงครั้งเดียว — ความเสี่ยงด้าน supply chain สูงมาก

> [!warning] CVE-2026-0300 (Palo Alto PAN-OS) — Patch Pending
> Buffer overflow ใน User-ID Authentication Portal ของ PAN-OS อนุญาต unauthenticated attacker รัน code สิทธิ์ root
> **Patch ยังไม่ออก** — คาด 13 May 2026; ควร monitor และ implement temporary mitigations
